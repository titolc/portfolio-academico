## Resumo

A partir de um PDF sobre alimentação saudável, montamos em inglês um plano para o "Joe Joestar": 25 anos, diabético, treinando para uma competição de levantamento de peso em 6 meses. O trabalho fala de nutrição, organização das refeições, o que evitar, hidratação, treino e cuidados com a diabetes, sempre citando a parte do PDF usada.
