## Resumo

Respondemos como seria a arquitetura de testes de uma loja online: quais camadas testar (unidade, integração, API e ponta a ponta), o que fica manual (exploratório, visual no celular), o que automatizar (cupom, estoque, frete, pagamento e pedido), quais ferramentas usar e quais testes rodam no pipeline.

Foi o primeiro contato com o assunto. Depois, na [atividade 10](../atividade-10-arquitetura-de-testes-medsupply/), fiz a mesma coisa sozinho, com um sistema maior.
