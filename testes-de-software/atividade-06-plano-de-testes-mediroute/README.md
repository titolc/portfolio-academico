## O que foi pedido

Fazer um plano de testes para a Release 1.0 da MediRoute, uma empresa fictícia que entrega medicamentos de farmácias para pacientes em Recife. Não precisava executar teste, só planejar.

## O que eu fiz

- Defini o escopo: o que entra e o que fica de fora da rodada de testes.
- Levantei os riscos, principalmente nos medicamentos controlados (receita) e refrigerados (temperatura).
- Escolhi os tipos de teste, o ambiente e a massa de dados.
- Coloquei critérios de entrada e de saída e quem é responsável por cada parte.
- Fechei com uma decisão de liberação: o que precisa estar ok pra release sair.

## O que aprendi

Que planejar teste é escolher prioridade. Não dá pra testar tudo, então o risco é o que decide por onde começar.
