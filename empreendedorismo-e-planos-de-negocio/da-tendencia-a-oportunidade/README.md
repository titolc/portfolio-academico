## Resumo

Partimos de uma tendência (as conexões entre startups, mentores e investidores estão ficando cada vez mais digitais) e seguimos o roteiro: tendência → mudança → público → problema → oportunidade.

A oportunidade que encontramos é justamente o **DaMatch**, o nosso [Projeto Integrador](../../projeto-integrador/). Essa atividade é a justificativa de negócio do projeto.
